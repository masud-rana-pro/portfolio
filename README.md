## 🚀 Overview

A modern, responsive personal portfolio website showcasing my professional journey, technical skills, projects, certifications, and research. The site is built with pure **HTML, CSS & JavaScript** — no framework overhead — and hosted on **GitHub Pages** for fast, free delivery.

### ✨ Key Highlights

- 🎨 **Premium Dark-Theme UI** with smooth gradient accents, glassmorphism cards and scroll-reveal animations
- 📱 **Fully Responsive** — pixel-perfect across mobile, tablet and desktop
- ⚡ **Zero-Framework** — lightweight, fast-loading static site with no build step required
- 🔤 **Animated Typing Effect** cycling through professional roles
- 🎬 **Embedded YouTube Demo** for flagship project with lazy-loaded iframe
- 📄 **Downloadable PDF CV** directly from the site
- ♿ **Accessible** — semantic HTML, skip-to-content link, ARIA labels and keyboard navigation

## 🖥️ Run Locally

No build step needed — just open the file in a browser:

```bash
# Clone the repository
git clone https://github.com/masud-rana-pro/portfolio.git

# Open in browser
start portfolio/index.html        # Windows
open portfolio/index.html         # macOS
xdg-open portfolio/index.html    # Linux
```

Or serve with any static server for live reload:

```bash
npx serve portfolio
```
